SECURITY LIMITATION
This is a static frontend demo access gate. Credentials are embedded in client-side JavaScript and can be discovered by a technically capable visitor. It is NOT secure production authentication and does not protect backend APIs or data. Before public deployment, replace this gate with server-side authentication, password hashing (Argon2id/bcrypt), secure HttpOnly SameSite cookies, CSRF protection, rate limiting, MFA for admins, and server-enforced role permissions. Do not use real financial/customer data.
