GOLDPAY ADMIN PANEL — LOGIN ENABLED DEMO

1. Extract this ZIP.
2. Open login.html.
3. Sign in with the credentials in LOGIN_CREDENTIALS.txt.
4. The admin dashboard opens after successful login.
5. Use Log out to end the browser session.

For reliable multi-page navigation, run the folder through a simple static web server or host it as a static site. Opening login.html directly may work in modern browsers, but browser file-origin rules can vary.

This is a frontend-only demo. Its login gate is not production-grade security. Read LOGIN_CREDENTIALS.txt before publishing it publicly.
